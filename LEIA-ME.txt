TESTE MAPA TGR 200 KM

Objetivo desta versão:
- testar SOMENTE o mapa PMTiles de 200 km;
- manter o restante do index.html original;
- sem PWA;
- sem Service Worker;
- sem botão de atualização offline;
- zoom da interface até 19;
- dados do PMTiles nativos até 15, com overzoom acima disso.

COMO TESTAR NO GITHUB
1. Faça backup do index.html atual.
2. Envie estes dois arquivos para a raiz do repositório:
   - index.html
   - mapa_tgr_200km.pmtiles
3. Aguarde o GitHub Pages atualizar.
4. Abra o link em aba anônima/privada para evitar cache antigo.
5. Verifique:
   - mapa aparece;
   - nomes de ruas/cidades aparecem;
   - zoom funciona até 19;
   - clientes/pedidos continuam aparecendo.

Esta versão ainda exige internet para:
- Leaflet;
- Protomaps Leaflet;
- SheetJS;
- QRCodeJS;
- carregamento do site pelo GitHub Pages.
O arquivo do mapa em si vem do repositório.
